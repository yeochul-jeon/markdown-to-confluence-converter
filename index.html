브라우저

  • 실시간 마크다운 → Confluence 위키 마크업 변환

CLI

  • 단일/복수 파일 일괄 변환
  • 디렉토리 재귀 탐색 (-r)
  • stdin/stdout 파이프 지원
  • esbuild 단일 파일 번들 배포

CLI 사용법

터미널에서 다수 파일을 일괄 변환하거나 CI/CD 파이프라인에 연동할 수 있습니다.

설치 및 빌드

프로젝트 루트 디렉토리(package.json이 있는 위치)에서 실행합니다.

npm install        # marked + esbuild 의존성 설치
npm run build      # dist/md2confluence.js 단일 파일 생성

npm run build는 esbuild로 cli.js, js/converter.js, marked를 하나의 파일로 번들링합니다. 빌드 후 dist/md2confluence.js 단일 파일로 배포 가능 (node_modules 불필요)

단일 파일 변환

node dist/md2confluence.js README.md

같은 디렉토리에 README.wiki 생성

복수 파일 / 디렉토리

node dist/md2confluence.js -r docs/

디렉토리 내 .md 파일을 재귀 탐색하여 변환

stdin 파이프

cat README.md | node dist/md2confluence.js

표준 입력을 받아 stdout으로 결과 출력

출력 디렉토리 지정

node dist/md2confluence.js -o output/ docs/*.md

변환 결과를 지정 디렉토리에 저장

옵션 레퍼런스

옵션 설명
-h, --help도움말 출력
-o, --output <경로>출력 디렉토리 지정 (기본: 입력 파일과 같은 위치)
-r, --recursive디렉토리 하위까지 재귀 탐색
-t, --theme <테마>코드 블록 테마 (예: Midnight, RDark)
--stdout결과를 stdout으로 출력 (파일 미생성)
